Brainstorm: Knowledge Graph
=====

Brainstorm: Knowledge Graph is a personalized nostr knowledge graph that is curated with the assistance of your trusted community.

BKR is designed to run on a remote server and to be accessible via the browser on any device. Each BKR will have a single owner/operator which is a nostr user. Login is via nostr. It will be designed to take advantage of personalized web of trust scores calculated by the NosFabrica flagship product: Brainstorm: Grapevine (BG). BG will perform the "heavy lifting" of culling the broader nostr landscape. 

Like BG, BKG will run a neo4j database. However, the memory requirements of BKG are intended to be lower than BG (at least for beginner users).
